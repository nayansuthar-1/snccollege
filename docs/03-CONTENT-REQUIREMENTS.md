**Purpose:** This is everything the website needs from the college that a developer cannot create. Until an item arrives, the site shows a neutral placeholder or hides that section. It never shows invented information.
**Status date:** 2026-10-09
**How to send:** Put files in a shared folder (Google Drive or similar) using the folder names given below. Send text answers as a document or email, numbered to match this list.
